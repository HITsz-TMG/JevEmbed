# Supervised format examples

`train.jsonl` and `validation.jsonl` contain small, independently authored examples for checking Choice, Score, and both Noul paths. They include hard and soft targets and expected Score values. They are not Open-Jev records and are not a performance benchmark.

For real training, prepare the pinned Open-Jev train/validation splits as described in the [training guide](../../docs/training.md). Keep downloaded data and trained adapters under `artifacts/` or `data/`.
